# NEXORA SCIENCE

## Projet d'intelligence artificielle scientifique

### Objectifs
- Analyser des données scientifiques.
- Créer des graphiques.
- Tester et comparer des modèles prédictifs.
- Générer des rapports scientifiques.

### Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Gradio

### État du projet
Prototype expérimental en développement.

Les premiers modèles n'ont pas surpassé la méthode de référence.
Des tests supplémentaires sont nécessaires.
